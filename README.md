# Homebrew tap for GumTree

Install the latest stable GumTree release with:

```sh
brew install GumTreeDiff/gumtree/gumtree
```

The formula installs the GumTree command-line distribution and its Java 17 runtime. To upgrade after a new formula release is published, run:

```sh
brew upgrade gumtree
```

The formula tracks stable releases from [GumTree](https://github.com/GumTreeDiff/gumtree/releases).
